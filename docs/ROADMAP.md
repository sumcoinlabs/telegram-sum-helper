# Sumcoin Helper: project direction

**Prime rule:** Running Sumcoin network/client code and live read-only network behavior outrank text explanations; reviewed, dated project documentation is next. Never claim an old podcast, social post, news article or scraped repository README is a verified current network rule. Keep any conflicting sources labeled with provenance.

**Behavior:** Quiet during ordinary chat; offer fast, accurate help when asked; keep conversations scoped to the requesting member; explain specific wallet, migration, peer-to-peer, and index issues in the member's language. Do not request secrets, promise price liquidity, or guarantee fund recovery.

**Learning:** Import anonymized historical question fingerprints onto the private VM, and continue safe group observation. Admin and developer statements are draft candidates, not automatic facts. Corrections require reviewed official evidence, explicit approval and reversible application. No user conversations or credentials go into public GitHub.

**AI:** Generate explanations only when deliberately enabled with credits/billing, verified project context and three request caps. Offline, deterministic, source-linked answers always work when the model fails or is disabled. Hard request caps alone do not guarantee a fixed dollar spend.

**Measure:** Use periodic anonymous weekly quality reports to see common questions, missing answers, feedback, review approvals, service reliability, and whether improvements reduce escalation. Focus future releases on intelligence and evaluation, not just adding FAQ items.

**AI provider flexibility (v0.0.15):** Both Groq-hosted OpenAI open-weight GPT-OSS and direct OpenAI Responses API are supported. Provider never gets raw historic exports, server secrets, or unreviewed group discussion as facts. Live price and other fixed operations stay deterministic; ambiguous currencies are clarified by code before any generative call.
